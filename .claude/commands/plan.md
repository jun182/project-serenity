argument-hint: <NNN or folder name>

Feature: $ARGUMENTS (folder in `specs/features/`).

1. Check `spec.md` is `approved`. If not, stop and say so.
2. Read the code the spec touches and the related `specs/system/` files.
3. Write `plan.md` from `specs/_templates/plan.md`: approach, files, constitution check, risks, how each acceptance criterion will be tested.
4. If the plan shows the spec is wrong or incomplete, propose the spec change and get it approved again before continuing.
